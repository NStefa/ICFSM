# ICFSM

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24235718.svg)](https://doi.org/10.5281/zenodo.24235718)

Supplementary material for the paper:

> Smaga, Ł., Stefańska, N., Kokoszka, P. (2026). Projection tests for linear
> hypothesis in the ill-conditioned function-on-scalar model.
> *Statistics in Transition new series*.

## Contents

The file [`ICFSM_supplement.pdf`](ICFSM_supplement.pdf) contains:

- a brief recall of the aggregation tests from Smaga and Stefańska (2025);
- proofs of the theorems stated in Section 3 of the main manuscript;
- comprehensive results of the simulation studies from Sections 4 and 5,
  together with illustrative examples of simulated data trajectories.

An R package implementing the proposed tests is under development and will be
linked here.
